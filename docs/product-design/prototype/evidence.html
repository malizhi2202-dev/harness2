Each `.txt` is the artifact converted to text by the SAME reader the
work is assessed through. An artifact that does not survive that
conversion is treated as unreadable however good it looks.

为什么同款读取器很重要：判分器读不出来的产物，在证据里也不该显得漂亮。

证据纪律（代码强制）

不截断轨迹整份写入；单条观测可按 obs_trunc 截断
无分数RunView 不带 score；判分在选择之后
绊线7 个 grader 标记，出现在文件名或内容 → 抛异常
答案键leak_globs 命中路径 → 进上下文前拒绝
同款读取产物用判分器自己的 extractor 渲染

这些不在证据里

  • rubric / 评分细则 / 参考答案
  • pass_rate、passed_count、判分摘要
  • 别的候选的 harness 与 run
  • 选择者的身份与选择理由

改进者看到的只有「做了什么、产出了什么」，看不到「得了几分」。

可点区：页签为静态演示（真实页面按页签切换树/产物/diff）· 复制目录 → toast。要点：证据里没有分数，这是 answer-free 设计的物理体现。
