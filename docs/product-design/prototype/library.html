怎么用（提示词的硬规矩）

  • 库里的 harness 不是你正在编辑的树：要用就 copy 组件进 context/harness/
  • copy 之后重新验证它的 workspace fact：上一个任务的映射/阈值在这里只是假设
  • 只抄组件不抄脚本 → 校验失败（引用的脚本不存在）

为什么这不等于「过拟合累积」
